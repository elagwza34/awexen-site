# Admin user guide

1. Open the AWEXEN dashboard as an owner or administrator and select Cost Calculator.
2. Edit projects, sections, questions, options, pricing rules, conditions and settings. Use reusable templates or duplicate an item to start from existing copy.
3. Enter prices in the configured minor currency unit. For EGP with 2 minor digits, enter `150000` for EGP 1,500. Choose Free, Included, or Manual review explicitly where applicable.
4. Preview scenarios, review validation messages, save the draft, and choose **Publish saved draft** when the configuration and amounts are approved.
5. To revert, copy an earlier version to draft, validate it, then publish it as a new version. Incoming requests use the new version. Historical quotations retain their issued figures.
6. Use Quotations and Leads for snapshot inspection and calculator lead stages. Customer communications and CRM conversion continue through Quote Inbox.

The starter catalog has no approved prices. Set real rates, mark inclusions, or select manual review before publishing. The live page is unavailable until a version is explicitly published.
