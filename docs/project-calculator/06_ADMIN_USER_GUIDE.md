# Admin user guide

1. Open the AWEXEN dashboard as an owner or administrator and select **حاسبة تكلفة المشاريع** (Cost Calculator). The dashboard is in Arabic, right to left, and opens on **ابدأ من هنا** (Start here): a four-step checklist (أنواع المشاريع، الخطوات والأسئلة، الأسعار، النشر) with a readiness badge and a shortcut to every screen.
2. Work through the checklist in order. Activate project types in **أنواع المشاريع**, create one or more steps in **خطوات الحاسبة**, add questions in **الأسئلة** and options in **الخيارات**, then price everything in **أسعار سريعة** by typing amounts in EGP directly; the form stores the minor currency units for you. A step marked **جاهز** is complete.
3. Each step is one screen in the public calculator. In **خطوات الحاسبة**, set **أظهر هذه الخطوة فقط عند تحقق إجابات سابقة** to branch the flow — for example show store questions only for store projects, or swap the process steps after a WordPress versus custom-development choice. A step can only depend on questions from earlier steps. The starter draft already uses this in two places: the custom-software scope question keeps only the platform steps the visitor selects, and choosing WordPress skips the Backend and database step. Each gate keeps an `empty` fallback, so the step still appears when the branching answer does not apply to the project or is left unanswered; clear a step's condition to make it unconditional again.
4. Rows without a price are flagged in amber in **أسعار سريعة**, and any unconfigured charge blocks publication. Use the **أسعار سريعة** screen for regular fixed prices, free items, included items, and manual quotes. Advanced rates (per unit, quantity tiers, percentages, caps) stay under **قواعد التسعير**, and optional conditional visibility lives under **المنطق والشروط**. The currency and decimal places are defined in **إعدادات العرض**.
5. Review scenarios in **معاينة واختبار** (Preview and test) and check **فحص ما قبل النشر** on the start screen. Choose **حفظ المسودة** (Save draft) to keep working, or **حفظ ونشر** (Save and publish) to save unsaved changes and publish them in one step. The header always shows whether you have unsaved changes and whether publishing is blocked.
6. To revert, restore an earlier version to draft from **سجل النشر** (Versions), validate it, then publish it again. Incoming requests use the new version. Historical quotations retain their issued figures.
7. Use **عروض الأسعار** (Quotations), **طلبات العملاء** (Leads), and **التحليلات** (Analytics) for snapshot inspection, calculator lead stages, and usage metrics. Customer communications and CRM conversion continue through Quote Inbox.

The starter catalog ships with approximate EGP starter rates so previews and estimates work end to end; review and replace them with approved commercial rates before publishing. Any charge left unconfigured blocks publication. The live page is unavailable until a version is explicitly published.
